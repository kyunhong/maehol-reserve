# 2학년 반별 상담 예약

2학년 1~10반이 반별로 쓰는 상담 예약 웹 앱입니다. 학생은 자기 반 달력에서 빈 시간을 골라 학번·이름·비밀번호로 예약하고, 같은 비밀번호로 나중에 취소·변경합니다. 담임 선생님은 자기 반 예약을 보고 설정을 바꿉니다.

- 화면: GitHub Pages
  - `index.html` + `app.js` 학생 예약 (반 고르기 → 반 달력)
  - `admin.html` + `admin.js` 담임 관리 (자기 반 달력·목록·설정)
  - `grade.html` + `grade.js` 학년 관리 (전 반 현황 보기, 담임 비밀번호 정하기)
  - `api.js` 서버 호출 + 데모 서버, `style.css`, `config.js`
- 서버·저장: Google Apps Script 하나 + 구글 시트 하나 (`apps-script/`)

## 동작 규칙

- **반끼리 완전히 독립**입니다. 6반 08:20 과 7반 08:20 은 다른 자리이고, 설정(제목·안내 문구·기간·시간대·휴무일)도 반마다 따로입니다.
- **학번은 5자리** (학년 1자리 + 반 2자리 + 번호 2자리, 예: `20601` = 2학년 6반 1번). 다른 반 학번으로는 예약할 수 없습니다. ("학번을 보면 7반 학생이에요. 7반 예약 화면에서 예약해 주세요.")
- 한 시간대에는 한 명만 예약됩니다. 오늘 날짜는 시간대 시작 시각이 지나면 마감됩니다.
- 예약할 때 정한 비밀번호로 **내 예약 확인 → 취소 / 변경** 할 수 있습니다. 비밀번호는 시트에 해시로만 저장됩니다.
- 비밀번호를 5번 틀리면 10분 동안 막힙니다 (학생은 학번별, 담임은 반별, 학년 관리는 따로).
- 다른 학생에게는 "예약됨"만 보이고 이름은 보이지 않습니다.

반마다 처음 설정은 아래와 같고, 담임이 **담임 관리 > 설정** 에서 코드 없이 바꿉니다.

| 요일 | 아침 | 점심시간 | 방과후 |
|---|---|---|---|
| 월·금 | 08:20~ | 13:30~ | 16:10~ |
| 화·수·목 | 08:20~ | 13:30~ | 17:10~ |

- 예약 화면 제목: `매홀고 2-<반> 상담 예약`, 예약 기간은 오늘부터 4주 뒤까지, 휴무일 없음.
- 처음 값은 `apps-script/Code.gs` 의 `defaultSettings_` 에 있습니다.

### 비밀번호는 세 종류

| 누가 | 무엇 | 어디에 저장 |
|---|---|---|
| 학생 | 자기 예약 확인·취소·변경 | 예약 시트 (해시) |
| 담임 (반마다 하나) | 자기 반 예약 보기, 자기 반 설정, 자기 비밀번호 바꾸기 | 스크립트 속성 `ADMIN_HASH_<반>` (해시, 자동 저장) |
| 학년 관리 (하나) | 전 반 예약 현황 보기, 담임 비밀번호 정하기·다시 정하기 | 스크립트 속성 `MASTER_PASSWORD` (직접 입력) |

학년 관리 비밀번호로는 담임 관리 화면에 들어갈 수 없습니다. 예약 취소·반 설정은 그 반 담임만 합니다. GitHub 에 공개되는 코드에는 어떤 비밀번호도 들어 있지 않습니다.

## 1. Apps Script 배포

1. 구글 드라이브에서 새 스프레드시트를 만듭니다 (예: "2학년 상담 예약").
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. `Code.gs` 내용을 모두 지우고 `apps-script/Code.gs` 내용을 붙여넣습니다.
4. 왼쪽 **⚙ 프로젝트 설정 → "appsscript.json 매니페스트 파일 표시"** 를 켜고, 편집기의 `appsscript.json` 을 `apps-script/appsscript.json` 내용으로 바꿉니다. (시간대 `Asia/Seoul`)
5. 함수 목록에서 `setup` 을 선택하고 **실행** → 권한 승인. 시트에 `예약`, `휴무일` 탭이 생깁니다.
6. **⚙ 프로젝트 설정 → 스크립트 속성 → 속성 추가**: 이름 `MASTER_PASSWORD`, 값에 학년 관리 비밀번호.
   - 담임 비밀번호(`ADMIN_HASH_…`)와 반 설정(`SETTINGS_…`)은 화면에서 저장하면 여기에 자동으로 생깁니다. 직접 만들거나 고치지 마세요.
7. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
8. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사합니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전** 으로 다시 배포해야 반영됩니다. (URL 은 그대로)

## 2. GitHub Pages 배포

1. `config.js` 의 `API_URL` 에 위에서 복사한 URL 을 넣습니다.
2. GitHub 에 새 저장소를 만들고 이 폴더를 올립니다.
   ```bash
   git remote add origin https://github.com/<아이디>/<저장소>.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Branch: `main` / `(root)`** 로 저장하면 몇 분 뒤 `https://<아이디>.github.io/<저장소>/` 에서 열립니다.

> GitHub Pages 는 `config.js` 같은 파일을 최대 10분 캐시합니다. 파일을 바꾸면 HTML 에서 그 파일을 부르는 `?v=` 숫자를 올려 주세요.

`API_URL` 을 비워 두면 브라우저에만 저장되는 **데모 모드**로 동작해서 화면만 미리 볼 수 있습니다. (데모에서는 담임·학년 관리 비밀번호를 아무거나 넣어도 들어가집니다.)

## 3. 처음 운영 준비 (학년 관리 담당)

1. `https://<아이디>.github.io/<저장소>/grade.html` 에서 `MASTER_PASSWORD` 로 들어갑니다.
2. **반별 현황** 표에서 각 반의 **정하기** 를 눌러 담임 비밀번호(6자 이상)를 정하고, 담임 선생님께 알려 드립니다.
3. 표의 **학생용 링크 복사** 로 반별 링크(`…/?반=6`)를 담임 선생님께 드리거나, 학생에게 첫 화면 주소를 주고 반을 고르게 합니다.

담임이 비밀번호를 잊으면 같은 화면에서 **다시 정하기** 를 누르면 됩니다 (5번 틀려 잠긴 것도 풀립니다).

## 담임 선생님용

`https://<아이디>.github.io/<저장소>/admin.html` 에서 반을 고르고 담임 비밀번호로 들어갑니다. (`admin.html?반=6` 으로 열면 6반이 미리 골라져 있습니다.)

- 위쪽에 **학생용 예약 링크** 와 복사 버튼이 있습니다.
- **달력**: 예약 기간의 현황을 주 단위로 봅니다. 칸마다 예약한 학생의 학번·이름이 보입니다.
- **목록**: 날짜별 표. "취소·지난 예약도 보기" 로 전체 기록도 볼 수 있습니다.
- **예약 취소**: 달력에서 예약된 칸을 누르거나, 목록의 **취소** 버튼을 눌러 우리 반 학생 예약을 취소합니다 (장난 예약 등). 그 시간은 다시 열리고, 시트에는 `취소 (담임 취소)` 로 기록이 남습니다.
- **시간 막기**: 달력에서 비어 있는 칸을 누르면 그 날짜의 그 시간대 한 칸만 예약을 막습니다 (회의·출장 등). 학생 화면에는 "마감"으로 보입니다. 막은 칸(빗금)을 다시 누르면 열립니다. 예약이 있는 칸은 먼저 예약을 취소해야 막을 수 있습니다.
- **여러 칸 한꺼번에 막기**: 달력 위 "여러 칸 한꺼번에 막기 · 다시 열기" 를 펼쳐 시간대(여러 개 가능)와 요일(월~금)을 체크하고 **막기** 를 누르면 예약 기간 전체(또는 정한 기간)에서 해당 칸이 모두 막힙니다. 예약이 이미 있는 칸과 휴무일은 건너뛰고, 건너뛴 예약을 알려 줍니다. **다시 열기** 로 같은 방식으로 풉니다.
- **설정**: 우리 반에만 적용됩니다. 저장하면 학생 화면에 곧바로 반영됩니다.
  - 예약 화면 제목, 안내 문구
  - 예약 기간: 시작 날짜 ~ 끝 날짜 (날짜 선택). 시작은 처음에 오늘로 채워져 있고, 지난 날짜가 되면 오늘부터 보입니다. 끝 날짜는 오늘부터 1년 안.
  - 상담 시간대: 이름, 시작 시각, 끝나는 시각(선택, 비우면 "08:20~" 처럼 시작만 보임), 열리는 요일(월~금 체크). 줄 추가·삭제 가능
  - 휴무일: 날짜와 사유
  - 바꾼 설정 때문에 없어지는 시간에 이미 예약이 있으면, 저장 전에 그 목록을 보여 주고 확인을 받은 뒤 그 예약들을 취소합니다.
  - 관리자 비밀번호 바꾸기

## 구글 시트에서 직접 관리

- **예약 목록**: `예약` 탭 (1~10반 모두). `반` 열로 구분합니다. 상태가 `예약` 인 행이 유효한 예약, 취소하면 `취소` 로 바뀝니다. 필터로 반을 골라 보면 편합니다.
- **직접 취소**: `예약` 탭에서 상태를 `취소` 로 바꾸면 그 자리가 다시 열립니다. 학생이 비밀번호를 잊으면 이렇게 취소해 주고 다시 예약하게 하면 됩니다.
- **휴무일**: `휴무일` 탭 A열에 날짜(`2026-10-20`), B열에 사유, C열에 반 번호를 적습니다. **C열을 비우면 학년 전체**, `6` 처럼 적으면 그 반만 쉽니다. (담임 설정의 휴무일과 함께 적용)

## 개발

서버 코드(`apps-script/Code.gs`)는 Apps Script 서비스를 흉내 낸 Node 테스트로 확인합니다 (Node 18 이상).

```bash
npm test
```

반별 예약 독립, 중복 예약 거절, 학번으로 반 확인, 학생 조회·변경·취소, 반별 담임 권한 분리, 학년 관리, 설정 저장·충돌 처리, 휴무일 등을 검사합니다. 학년·반 수를 바꾸려면 `Code.gs` 의 `CONFIG` 와 `config.js` 를 같이 고칩니다.
